# 行前准备与出行常识

## 证件与身份材料

- 国内出行以**居民身份证**为通用凭证，高铁、飞机、酒店入住、景区实名预约都依赖它，务必随身携带原件。
- 身份证消磁或丢失时，可在车站公安制证口办理**临时乘车身份证明**，或用 12306 App 申请电子临时身份证明（有次数限制）。
- 未满 16 周岁未成年人可用户口本、出生医学证明等；带小孩出行建议同时带上户口本，部分景区与酒店会核验。
- 出境另需护照与签证，注意**护照有效期需在回程后仍剩余 6 个月以上**，很多国家对空白页数量也有要求。
- 建议把证件拍照存进手机相册（或云盘）备用，原件与复印件分开放，避免一起丢失。

## 预约与门票

- 热门景区与博物馆普遍实行**实名预约制**，多数需提前 1-7 天在官方渠道预约，节假日放票即满，务必提前抢。
- 预约用的证件必须与现场核验的证件一致，用他人身份预约会导致无法入园。
- 部分场馆**周一闭馆**（博物馆、美术馆居多），安排行程前先确认开放日。
- 景区门票与开放时间会随季节调整，出行前一天再到官方渠道核对一次。
- 门票优先在景区官方公众号或官方合作平台购买，避免二手转让票无法核验。

## 装备清单

- 通用四件套：**充电宝、数据线、雨具、常用药**。
- 充电宝需标识清晰且有 3C 认证；无标识或鼓包的老旧充电宝会被安检拦下。
- 常用药建议带：退烧止痛、肠胃药、抗过敏药、创可贴、晕车药；有慢性病的按行程天数多备一档。
- 出行前查目的地近 3 天天气，据此决定是否带防晒、保暖层、防水鞋。
- 长时间步行或爬山建议穿**已磨合过的**运动鞋，新鞋容易磨脚。

## 保险与应急准备

- 短途周边游一般可用意外险覆盖；涉及登山、潜水、滑雪、高原等高危项目时，需选择**包含该项目的专项意外险**，普通意外险通常免责。
- 购买时看清免责条款与紧急救援服务范围，高原、无人区线路建议选带直升机救援的产品。
- 保存目的地**当地急救电话（120）、报警（110）**及所购保险的报案电话，单独记在纸质便签上以防手机没电。
- 把同行人的联系方式、住宿地址告知一位不随行的亲友。

## 支付与网络

- 国内绝大多数场景支持移动支付，但**仍需备少量现金**：部分山区景区、乡镇集市、寺庙香火处可能不支持扫码。
- 跨省无需换卡换号；出境需提前开通国际漫游或购买当地流量卡/eSIM。
- 目的地为偏远地区时，提前下载**离线地图**，山区与高速路段常有信号盲区。
- 住宿、门票等大额消费尽量走官方渠道，避免私下转账。
